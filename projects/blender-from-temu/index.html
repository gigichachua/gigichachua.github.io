BlenderFromTemu

Blender-inspired mesh editor built from scratch in pure C and modern OpenGL.

Year
2026
Built with
  • C
  • OpenGL
  • GLFW
  • GLAD

I built this project from scratch in pure C and modern OpenGL to better understand how 3D editors and rendering tools work under the hood.

Instead of relying on an engine or editor framework, I implemented the core interaction loop myself: selecting vertices by click or box, adding vertices and faces, deleting vertices, moving them with a translate gizmo that has axis lock and snapping, undoing and redoing changes, and saving the results back out as OBJ files.

Working on it gave me a much better understanding of lower-level graphics programming, mesh editing workflows, and the kind of tooling problems game engines usually hide.
