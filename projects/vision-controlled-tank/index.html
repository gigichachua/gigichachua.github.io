Vision-Controlled Tank

Computer vision control system that lets a UE5 tank be driven with head movement, winks, and hand gestures through a Python-to-Unreal input pipeline.

Built with

  • MediaPipe
  • OpenCV
  • OSC
  • Computer Vision

I used my tank game as a testbed for an unusual control system: driving gameplay through camera input instead of standard controls.

Head movement aimed the turret, winks fired and changed weapons, and hand gestures controlled steering and driving.

The interesting part was not just making it work, but making it usable. Camera input is noisy, so a big part of this project was stabilizing signals and turning them into controls that felt responsive inside Unreal Engine.

The tank itself comes from my Tank Combat project, which is built on a Marketplace pack. The control pipeline, Python integration, and input handling are mine.
