Tank Combat + ML AI

UE5 tank project with multiple tank types, projectile-based combat, scripted bots, and a PyTorch imitation model, with reinforcement learning being rebuilt.

I built this tank project in Unreal Engine 5 as both a playable combat game and a space for machine learning AI experiments.

The tank pawn, including driving, turret, and weapons, started from a Marketplace tank pack. On top of it I built the AI, the machine learning pipeline, teams, health, scoring, respawning, the HUD and minimap, and the integration of two more tank types with different strengths and weaknesses.

In an earlier version, since lost, I trained reinforcement learning agents. My first approach let reinforcement learning handle too much of the problem, which led to unstable results. The better solution was a hybrid system: code handled the physics-heavy parts like aiming, while reinforcement learning focused on higher-level combat decisions, and in my own playtests it could beat me. I am rebuilding that training now.

What survives is a scripted bot with ballistic lead aiming and a PyTorch imitation model. I recorded about a million frames of the bot playing and trained the model on them, and it plays live through a Python server over OSC.
